\subsection{Linearity and linear functionals}

The grid picture of
\autoref{sec:linear-algebra-i:bases-to-transformations} is an instance of
a general principle. A linear map respects addition and scaling in the
domain, even when its inputs are functions or matrices rather than points
of a plane. The following definition states that principle without
depending on coordinates.

\begin{definition}
  Let \(V\) and \(W\) be vector spaces over the same field \(\mathbb F\).
  A map \(L:V\to W\) is linear if the identities
  \[
    L(v+w)=L(v)+L(w),\qquad L(av)=aL(v)
  \]
  hold for \(v,w\in V\) and \(a\in\mathbb F\). These identities
  express preservation of addition and scalar multiplication. Equivalently,
  \[
    L(av+bw)=aL(v)+bL(w)
  \]
  for all \(a,b\in\mathbb F\) and \(v,w\in V\).
  When \(W=\mathbb F\), a linear map is called a linear functional.
\end{definition}

In particular, \(L(0_V)=0_W\).
A function between vector spaces must satisfy the displayed identities to
be linear. Its domain and codomain provide the vector-space operations
with which this additional requirement is expressed.

\begin{example}
  If \(E=(e_1,e_2)\) is a basis of \(V\), write
  \(a_1=L(e_1)\), \(a_2=L(e_2)\) for a linear functional \(L\).
  For \(v=c_1e_1+c_2e_2\),
  \[
    L(v)=c_1L(e_1)+c_2L(e_2)=c_1a_1+c_2a_2.
  \]
\end{example}

\subsection{Why a linear map preserves grid structure}
\label{sec:linear-algebra-i:linear-map-grids}

% Source: images/primitives/IMG_9444--9445.jpeg; the author requested
% explicit explanations of parallelism, equal spacing, and grid diagrams.
For a real vector space, a line with starting point \(p\) and nonzero
direction \(d\) consists of vectors \(p+td\), where \(t\in\R\).
Linearity gives
\[
  L(p+td)=L(p)+tL(d).
\]
If \(L(d)\ne0\), these images form a line with direction \(L(d)\).
Lines sharing the direction \(d\) therefore have images sharing the
direction \(L(d)\), so the image lines are parallel or coincide.
If \(L(d)=0\), the entire line maps to the single point \(L(p)\).

Equal spacing comes from the same identity. Consecutive inputs
\(p+kd\), for integer \(k\), differ by \(d\). Their images differ by
the constant vector \(L(d)\), since
\[
  L(p+(k+1)d)-L(p+kd)=L(d).
\]
Every input step in this direction produces the same output step,
wherever it is taken. In a two-dimensional grid generated by
\(e_1,e_2\), the two step vectors become \(L(e_1),L(e_2)\).
If these remain independent, the result is a parallelogram grid, with
uniform spacing within each parallel family. The two spacings need not
be equal to one another or to their original values. Angles and lengths
may change.

Parallel lines alone do not capture this condition.
\autoref{fig:linear-algebra-i:unequal-grid-steps} redraws a grid in
which parallel lines survive but equal input steps have unequal image
steps. Such an action cannot be linear. These pictures illustrate
consequences of linearity. The definition still requires the identities
for every vector and scalar, rather than just the finitely many points
visible in a drawing.
\begin{figure}[htbp]
  \centering
  \input{figures/unequal-grid-steps}
  \caption[Parallelism without equal steps]{Schematic of a failure of
    linearity. The three marked input points are equally spaced on a
    line, but their three images are not. Parallel grid lines and a
    fixed origin do not repair the unequal steps.}
  \label{fig:linear-algebra-i:unequal-grid-steps}
\end{figure}

The possibility of collapse is equally important. If the two image step
vectors are dependent, a planar grid can collapse to a line, and if both
are zero it collapses to the origin. These maps still preserve linear
combinations. The kernel and image in
\autoref{ch:linear-algebra-i:kernel-image-and-rank} describe the lost
directions and the output space that remains.
For example, when \(L(e_1)=u\ne0\) and \(L(e_2)=0\),
\[
  L(ae_1+be_2)=au.
\]
The output retains the first coefficient, while every change in the
second coefficient gives the same output. This case is shown in
\autoref{fig:linear-algebra-i:collapsed-grid}.

\subsection{Prescribing a map on a basis}

The grid discussion explains why it suffices to track basis vectors.
Every other vector is assembled from them, and linearity retains its
coefficients. The same argument applies in any vector space with a finite
basis, without a geometric grid.

Let \((v_1,\ldots,v_m)\) be a basis of \(V\). For each \(j\), choose
a vector \(w_j\in W\). The prescription
\[
  L(v_j)=w_j,\qquad 1\leq j\leq m,
\]
determines a linear map on all of \(V\). For
\(v=a^1v_1+\cdots+a^mv_m\), its value is
\[
  L(v)=a^1w_1+\cdots+a^mw_m.
\]

\begin{example}[Recovering matrix columns from a coordinate rule]
  \label{ex:linear-algebra-i:coordinate-rule-matrix-columns}
  Define \(L:\R^2\to\R^2\) by
  \[
    L(v^1,v^2)=(3v^1-2v^2,\;5v^1+6v^2).
  \]
  % Expanded from September 17 PDF p. 20 at Lucas's request, November 11.
  \begin{pendingreview}
  Each output coordinate is a linear combination of the input coordinates.
  Coordinatewise addition and scalar multiplication therefore make \(L\)
  linear.
  The images of the standard basis vectors are
  \[
    L(1,0)=(3,5),\qquad L(0,1)=(-2,6).
  \]
  Since \((v^1,v^2)=v^1(1,0)+v^2(0,1)\), linearity gives
  \[
    \begin{aligned}
      L(v)&=v^1(3,5)+v^2(-2,6)\\
        &=\begin{bmatrix}3&-2\\5&6\end{bmatrix}
          \begin{bmatrix}v^1\\v^2\end{bmatrix}.
    \end{aligned}
  \]
  Thus the first column is \(L(1,0)\), and the second is \(L(0,1)\).
  The same two images determine the value at every input. For instance,
  \[
    \begin{aligned}
      L(1,1)&=L(1,0)+L(0,1)\\
        &=(3-2,5+6)=(1,11),\\
      L(-2,3)&=-2L(1,0)+3L(0,1)\\
        &=(-6-6,-10+18)=(-12,8).
    \end{aligned}
  \]
  \end{pendingreview}
\end{example}

\begin{example}[Two input coordinates and three output coordinates]
  \label{ex:linear-algebra-i:two-to-three-coordinate-map}
  % Source: September 17 PDF p. 25. Expanded November 11, 2026.
  \begin{pendingreview}
  The map \(T:\R^2\to\R^3\) is given by
  \[
    T(v^1,v^2)=
      \begin{bmatrix}2v^1-v^2\\v^1+v^2\\-v^1+3v^2\end{bmatrix}.
  \]
  Setting one input coordinate to \(1\) and the other to \(0\) gives
  \[
    T(e_1)=\begin{bmatrix}2\\1\\-1\end{bmatrix},\qquad
    T(e_2)=\begin{bmatrix}-1\\1\\3\end{bmatrix}.
  \]
  For an arbitrary input, the component formula becomes
  \[
    \begin{aligned}
      T(v)&=v^1\begin{bmatrix}2\\1\\-1\end{bmatrix}
             +v^2\begin{bmatrix}-1\\1\\3\end{bmatrix}\\
        &=\begin{bmatrix}2&-1\\1&1\\-1&3\end{bmatrix}
          \begin{bmatrix}v^1\\v^2\end{bmatrix}.
    \end{aligned}
  \]
  The two input basis vectors supply two columns. Each image needs three
  output coordinates, so the matrix has three rows and two columns.
  \end{pendingreview}
\end{example}

\subsection{The vector space of linear maps}

The linear maps \(V\to W\) form a vector space, denoted
\(\mathcal L(V,W)\), under the pointwise operations
\[
  (L_1+L_2)(v)=L_1(v)+L_2(v),\qquad (aL)(v)=aL(v).
\]
If \(\dim V=m\) and \(\dim W=n\), choosing bases identifies this space
with the space of \(n\)-by-\(m\) matrices. The correspondence is developed
in \autoref{sec:linear-algebra-i:change-of-basis-for-functions-and-maps}.
