\chapter{Linear equations and maps}
\label{ch:linear-algebra-i:linear-equations-and-maps}

Matrix multiplication turns a system of linear equations into one equation
\(Ax=b\). We first use row operations to study that equation, then examine
the linear map \(x\mapsto Ax\) behind it. Choosing different bases changes
the representing matrix, while composition and inversion of maps become
matrix multiplication and inversion.
